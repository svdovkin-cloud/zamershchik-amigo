## Как проверить результат

1. **Canonical**
   ```js
   document.querySelectorAll('link[rel="canonical"]').length   // должно быть 1
   ```
2. **Разметка** — https://validator.schema.org/ → вставить URL
3. **SEO-аудит** — PageSpeed Insights / Яндекс.Вебмастер → «Инструменты → Анализ оптимизации»
4. **Индексация** — Яндекс.Вебмастер → «Индексация → Отправить URL», затем «Мониторинг»
5. **Скорость** — https://pagespeed.web.dev/analysis?url=https://pro-zhaluzi.ru

## Важно

Все файлы в `fixes/` — это **готовые к вставке** коды, но их нужно применить
в панели управления сайтом. Самостоятельно изменить сайт из этой папки нельзя.

Перед внедрением проверьте, что ваша платформа не генерирует `canonical`
автоматически — иначе будет дубль тега. Сейчас она генерирует
**невалидный** (с кавычками `“ ”`), поэтому замена безопасна.

Перед вставкой JSON-LD с ценами обязательно добавьте цены в видимый текст —
Google трактует несоответствие разметки и контента как спам.
