# Внутренняя перелинковка

## Текущее состояние

Главное меню содержит ~30 ссылок и работает корректно — все они ведут на
существующие страницы из sitemap. Это уже хорошо.

**Но** внутри текста ссылок почти нет: между статьями и каталогом переходов не организовано.
Коммерческие страницы получают трафик только из меню, а блог (`/articles`) —
практически изолирован.

## Зачем это нужно

1. **Статический вес.** Страницы блога не связаны с каталогом → не передают коммерческий вес.
2. **Глубина краулинга.** Google должен доходить до каждой страницы ≤3 клика от главной.
3. **Тематическая связность.** Ссылки из статьи «как выбрать жалюзи» на конкретные
   жалюзи = подтверждение тематики страницы.
4. **Поведенческие факторы.** Меньше тупиков → выше вовлечённость.

### 3. Блоки перелинковки в подвале

Сейчас подвал содержит только служебные ссылки. Добавьте **футер-каталог** —
это стандартная практика для SEO-сайтов:

```
Жалюзи            Шторы                Статьи
Горизонтальные →  Рулонные →           Как выбрать жалюзи
Деревянные     →  Блэкаут     →        Как сделать замер
Бамбуковые    →  День-ночь  →        Как ухаживать за жалюзи
Вертикальные  →  Кассетные   →        Жалюзи для помещений
Тканевые      →  ZIP уличные →        Как заказать рулонные шторы
Рachel        →  Римские     →        Какие жалюзи для школы
Автоматические → Плиссе       →       Жалюзи или шторы
```

Все ссылки — обычные `<a href="...">` с осмысленным анкором (не «подробнее», не картинка без alt).

### 4. Хлебные крошки (BreadcrumbList)

Разметка уже подготовлена в `fixes/head-page-template.html` — скрипт
подставляет `BreadcrumbList` автоматически на всех внутренних страницах.

Визуальные крошки (для пользователя) добавьте на все страницы каталога:

```
Главная / Каталог штор / Рулонные шторы
```

## Правила анкоров

**Хорошие** (описательные):
- `купить вертикальные жалюзи в Самаре`
- `рулонные шторы блэкаут с монтажом`
- `как правильно сделать замер жалюзи`

- одинаковый анктор «Жалюзи» на 15 разных страницах

## Убрать «тупиковые» ссылки

`<a href="">` в футере Яндекс.Карт — это ссылка без адреса. Поисковик не может
за ней перейти, Lighthouse ругается на `crawlable-anchors`. Либо задайте адрес,
либо замените на `<span>`: те же 7 ссылок `<a>` вообще без `href` (кнопки закрытия
попапов) добавьте `role="button"` и `aria-label`:

```html
<a class="wind-close" role="button" aria-label="Закрыть" tabindex="0"></a>
```
