| Без width/height | 155 | — |

**282 изображения** вообще не имеют атрибута `alt` — их нужно заполнить.
`alt=""` на декоративных картинках (иконки, разделители, логотипы-ссылки) — **корректно**, их не трогаем.

## Правила заполнения

1. **Alt ≠ подпись под фото.** Alt читают поисковик и скринридер, он заменяет невидимую картинку.
2. Описывайте **что видно + для чего**, добавляя гео- и продуктовый ключ.
3. 100–160 символов — оптимально.
4. Не спамьте ключами: «жалюзи жалюзи жалюзи Самара купить жалюзи» — ухудшает выдачу.
5. НЕ начинайте с «изображение», «фото», «картинка» — поисковик добавляет это сам.
6. Ключи склоняйте естественно: «жалюзи в Самаре», не «жаалюзи в Самара».

## Как получить полный список картинок без alt

В адресной строке открытой страницы вставьте в консоль браузера (F12 → Console):

```js
Array.from(document.querySelectorAll('img:not([alt])'))
  .map(i => i.currentSrc || i.src)
  .forEach((u, n) => console.log((n+1) + '\t' + u));
```

Или сохранить в файл:

```js
copy(Array.from(document.querySelectorAll('img:not([alt])'))
  .map(i => (i.currentSrc || i.src) + '\t' + i.alt).join('\n'));
```

## width/height

Обязательно проставьте на **все 155** изображений главной (и на остальных страницах),
иначе при загрузке страница прыгает и падает CLS в Core Web Vitals.

Прописать можно прямо в `<img>`:

```html
<img src="..."
     width="1169"
     height="572"
     loading="lazy"
     decoding="async"
     alt="Горизонтальные алюминиевые жалюзи — каталог PRO Жалюзи, Самара">
```

- `width`/`height` — реальные пропорции изображения
- `loading="lazy"` — для картинок **ниже первого экрана** (на главной уже стоит на 200 шт.)
- `decoding="async"` — не блокирует отрисовку

**Не ставьте `loading="lazy"`** на главном экране — там нужен `fetchpriority="high"`:

```html
<img src="..."
     width="1169" height="572"
     fetchpriority="high"
     decoding="async"
     alt="...">
```

## Адаптивность (srcset)

Сейчас `srcset` — **0 вхождений** на всём сайте: одна и та же картинка 1920px
отдаётся и на 360px-телефоне. Добавьте:

```html
<img src=".../f.png"
     srcset=".../-/resize/480/f.png   480w,
             .../-/resize/768/f.png   768w,
             .../-/resize/1200/f.png 1200w,
             .../-/resize/1920/f.png 1920w"
     sizes="(max-width: 500px) 370px, 1170px"
     width="1170" height="572"
     alt="...">
```

На CDN `m-files.cdn1.cc` путь изменения размера уже виден в существующих URL:
`/-/resize/1920/f.png` → заменить `1920` на нужную ширину.

## WebP/AVIF

Сейчас на всём сайте только **2** упоминания webp. Попросите хостинг/CDN отдавать
современные форматы по заголовку `Accept`:

```nginx
location ~* \.(png|jpe?g)$ {
    avif "/path/to/[email protected]" f=avif;
    webp "/path/to/[email protected]" f=webp;
}
```

## Логотипы соцсетей (alt="")

У этих ссылок alt пустой, хотя они кликабельные — скринридер не понимает, куда ведёт ссылка
(ошибка Lighthouse `link-name`, 14 элементов):

```html
<!-- как есть -->
<a class="social-media__item" href="https://vk.com/prozhaluzi63">
  <div class="social-media__logo"></div>
</a>

<!-- нужно -->
<a class="social-media__item" href="https://vk.com/prozhaluzi63"
   aria-label="PRO Жалюзи во ВКонтакте"
   title="PRO Жалюзи во ВКонтакте"
   rel="nofollow noopener">
  <div class="social-media__logo"></div>
</a>
```

Аналогично для Telegram, RUTUBE, MAX, Авито.
