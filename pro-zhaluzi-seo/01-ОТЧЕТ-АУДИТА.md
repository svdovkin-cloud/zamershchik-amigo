## 🔴 КРИТИЧНО — блокирует индексацию и контроль над выдачей

### 1. Canonical не работает ни на одной странице (0/41)

**Что найдено** — на 15 страницах тег присутствует, но написан «умными» кавычками U+201D:

```html
<!-- как есть на сайте (СЛОМАНО) -->
<link rel=”canonical” href=”https://pro-zhaluzi.ru/”>
```

Это не валидный HTML. Браузер не создаёт элемент `link[rel="canonical"]`.
Проверено в DOM загруженной главной страницы: `document.querySelectorAll('link[rel="canonical"]').length === 0`.

**Остальные 26 страниц** не имеют canonical вообще.

**Почему это критично:** сайт не может объединить дубли (`/rulonnye-shtory-blekaut` ↔ `/rulonnayz-shtora-blackout`), задать приоритет версий с www/HTTPS/ trailing slash, передать сигналы консолидации.

**Исправление:** заменить на прямые кавычки, добавить на все страницы. См. `fixes/head-critical.html`.

## 🟡 СРЕДНИЙ ПРИОРИТЕТ

### 10. `og:url` относительный на 41/41 страницах

```html
<!-- как есть -->
<meta property="og:url" content="pro-zhaluzi.ru"/>
<!-- нужно -->
<meta property="og:url" content="https://pro-zhaluzi.ru/"/>
```
Также отсутствуют на всех страницах: `twitter:card`, `og:image:alt`, `og:image:width`, `og:image:height`.

### 11. Viewport запрещает масштабирование

```html
<meta name="viewport" content="width=device-width,user-scalable=1.0,initial-scale=1.0,maximum-scale=1.0"/>
```
`maximum-scale=1.0` отключает пинч-зум → Lighthouse `meta-viewport` FAIL, штраф за мобильную удобочитаемость.
**Нужно:** убрать `user-scalable` и `maximum-scale`.

### 12. Адаптивность: единственный брейкпоинт — 500px

```css
body,#site_wrapper1{min-width:1170px;}          /* всё, что шире 500px */
@media (max-width: 500px){body,#site_wrapper1{min-width:370px;}}
```
На планшетах и ноутбуках 501–1169 px вёрстка принудительно 1170 px → горизонтальная прокрутка. Нужны брейкпоинты 768/1024/1170.

### 19. Sitemap.xml

- `changefreq: always` на **всех 41** URL — некорректно (Google игнорирует; Yandex переобход по спаму)

- `lastmod` у всех страниц = дата сборки сайта (09.10.2026) — будет «обновляться» при каждой пересборке
- нет `<priority>`; нет `hreflang`-пар
- в sitemap попадает `/newpage`, `/stocks`, `/map`

Нет `CleanParam` для UTM-меток, нет `Disallow` для служебных параметров.
