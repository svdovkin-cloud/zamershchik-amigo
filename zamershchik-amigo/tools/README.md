# Служебные стенды для разработки

Эти файлы нужны только при разработке. В работу приложения они не попадают:
сервер отдаёт исключительно папку `public/`.

| Файл | Зачем |
|---|---|
| `mock-backend.ps1` | Макет сервера на чистом PowerShell — поднимает статику и проксирует каталог и расчёт в настоящий Amigo. Позволяет открыть интерфейс на компьютере **без Node** и посмотреть, как приложение выглядит на реальном прайсе. Заявки не отправляет. |
| `static-server.ps1` | Просто статика из корня проекта. Нужен для стенда проверки синтаксиса. |
| `syntax-check.html` | Прогоняет JS-файлы через парсер браузера и показывает ошибки. Смысл в том, что фронтенд — обычные файлы без сборщика: синтаксис можно проверить, просто открыв страницу и выбрав файлы. |

## Как пользоваться

Макет сервера:

```powershell
powershell -ExecutionPolicy Bypass -File tools\mock-backend.ps1 -Port 8787
```

Затем открыть `http://127.0.0.1:8787/`. PIN — любой четырёхзначный, например `1234`.
Это позволяет посмотреть интерфейс и цены до установки Node.

Проверка синтаксиса:

```powershell
powershell -ExecutionPolicy Bypass -File tools\static-server.ps1 -Port 8788
```

Открыть `http://127.0.0.1:8788/tools/syntax-check.html` и выбрать файлы.

## Замечание про кодировку

PowerShell 5.1 читает `.ps1` как ANSI и ломает кириллицу. Поэтому при правке
этих файлов из PowerShell сохраняйте их в UTF-8 **с BOM**:

```powershell
$enc = New-Object System.Text.UTF8Encoding($true)
[System.IO.File]::WriteAllText($path, [System.IO.File]::ReadAllText($path, [System.Text.Encoding]::UTF8), $enc)
```

Файлы `.js`, `.mjs`, `.html` и `.css` BOM не нужен — там всё в порядке.
